About MedLife

Built for Secure Healthcare

MedLife is a final-year university lab project demonstrating a cryptographically secure medical referral system — combining modern web principles with applied cryptography.

Our Mission

Reimagining Medical
Data Security

Traditional healthcare referral systems transmit sensitive patient data through insecure channels — emails, fax, and unencrypted portals. MedLife is our answer to this systemic problem.

By applying proven cryptographic principles — symmetric encryption, public key infrastructure, digital signatures, and message authentication codes — we demonstrate that secure healthcare communication is not only possible but practical.
