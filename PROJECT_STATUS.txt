✅ 1. Login and Registration Modules
   - Complete user registration with email, username, password
   - Login with email/password validation
   - Session management with secure tokens
   - Admin approval system

✅ 2. User Information Encryption During Registration
   - Email encrypted with RSA
   - NID/contact info encrypted with RSA
   - All user data encrypted before storage
   - Automatic decryption on retrieval

✅ 3. Password Hashing and Salting
   - SHA-256 hashing (from scratch, not built-in)
   - Random 16-byte salt per password
   - Salt + hash stored together in database
   - Rainbow table and dictionary attack protection

✅ 4. Two-Step Authentication (2FA)
   - Step 1: Email + Password validation
   - Step 2: 6-digit verification code
   - Both steps required for access
   - Verification codes display during registration for testing

✅ 5. Key Management Module
   - RSA key pair generation per user (256-bit demo, 2048+ production)
   - ECC key pair generation per user
   - Key storage in database
   - Key retrieval for encryption/decryption operations

✅ 6. Create, View, Edit Posts and Profiles
   - Create: Prescriptions, Referrals, Messages
   - View: User profiles, message history, prescriptions
   - Edit: User profile information
   - All operations with automatic encryption/decryption

✅ 7. Critical Data Encrypted in Database
   - User emails: RSA encrypted
   - User NID: RSA encrypted
   - Messages: ECC encrypted
   - Prescriptions: RSA encrypted
   - Referrals: RSA signed and encrypted
   - Passwords: SHA-256 hashed with salt
   - All encrypted before storage, all plaintext never in database

✅ 8. Message Authentication Codes (MAC)
   - HMAC-SHA256 implementation from scratch
   - 64-round SHA-256 compression function
   - RFC 2104 HMAC algorithm (ipad/opad)
   - MAC verification with constant-time comparison
   - Detects message tampering and unauthorized modifications

✅ 9. Asymmetric Encryption Only
   - RSA used for user data encryption (asymmetric)
   - ECC used for message encryption (asymmetric)
   - NO symmetric encryption (AES, DES, 3DES, ChaCha20, Fernet, etc.)
   - NO built-in crypto library imports
   - All encryption is asymmetric

✅ 10. Two Different Asymmetric Algorithms
   - RSA: 6-step key generation with Miller-Rabin primes
   - ECC: Elliptic curve point arithmetic
   - Both used together in the system
   - RSA encrypts user identity data
   - ECC encrypts messages
   - Cannot replace one with other

✅ 11. Role-Based Access Control (RBAC)
   - Admin: User approval, system management
   - Doctor: Create prescriptions, refer specialists
   - Patient: View prescriptions, send messages
   - Specialist: Receive referrals, provide consultations
   - Role checked on every protected route
   - Admin-only operations protected
   - Different dashboards per role

✅ 12. Secure Session Management
   - Flask signed sessions (cryptographically secured)
   - User ID validated on every request
   - Role-based session permissions
   - 2FA required before session grant
   - Logout clears session completely
   - Session hijacking prevention via database validation
